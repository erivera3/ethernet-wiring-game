Build either Ethernet wiring standard. Select a wire, then tap its pin—or drag it into place.

My memory method · open when you need it

Memorize the fixed wires first, then check A or B.

  1. Brown at the end: 7–8. White/brown, then solid brown.
  2. Blue in the middle: 4–5. Flip the usual stripe-first order: 4 = solid blue, 5 = white/blue.
  3. Choose the first pair: 1–2.
    🏀 B = Basketball = Orange: white/orange, then solid orange.
    👽 A = Alien snot = Green: white/green, then solid green.
  4. Fill what’s left: 3 and 6. Use the remaining color—green for B, orange for A. 3 = white stripe, 6 = solid.

My sequence: 7–8 → 4–5 → 1–2 → 3–6.
Stripe first in each pair except blue. Close this guide, build from memory, check, and repeat.

Why this helps you learn

This routine reduces eight wire positions to four pairs and a consistent sequence. It uses established learning principles; it is a memory aid, not a guarantee that you will remember.

  • Fixed anchors: blue and brown stay in the same positions in both standards, reducing what you must work out each time.
  • Chunking: learn four pairs and one repeatable routine instead of eight disconnected facts.
  • Distinctive cues: basketball orange and alien-snot green connect each standard to a vivid image that can help you retrieve the starting color.
  • A clear exception: stripe first within each pair by pin number—except blue: solid at 4, stripe at 5.
  • Retrieval practice and feedback: close this guide, build from empty pins, then check your answer and correct mistakes. Recalling the order gives you practice that simply looking at the answer does not.
  • Spacing and mixing: come back tomorrow, then a few days later. Once you can do each standard, alternate A and B to practice choosing the right order.

One correct attempt is not mastery. Aim to wire both standards correctly from memory across several sessions. With practice, recall can become faster and require less conscious effort; no claim about a specific brain region is needed.
